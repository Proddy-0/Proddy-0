### 🧪 Proddyt Labs

A personal ecosystem of apps I build and self-host. They share a common identity provider (`gate`) and are designed to work together.

| Project | What it is | Stack |
|---|---|---|
| [`labs-gate`](https://github.com/Proddy-0/labs-gate) | Identity provider — OAuth2 / OIDC SSO that authenticates every other Labs app | TypeScript · Node · Prisma |
| [`labs-punch`](https://github.com/Proddy-0/labs-punch) | Internal time-tracking for work hours (entry/exit, history, JWT + Authentik) | Vue 3 · Express · Prisma · Postgres |
| [`labs-nexo`](https://github.com/Proddy-0/labs-nexo) | Collaborative second brain — notes (TipTap), collections, kanban, knowledge graph, real-time multi-workspace with Obsidian import | Vue 3 · TipTap · Socket.io · Prisma · Postgres |
| [`labs-vector`](https://github.com/Proddy-0/labs-vector) | Tasks & project management, integrated with Gate SSO | Vue 3 · Express · Prisma · Postgres |
| [`labs-wire`](https://github.com/Proddy-0/labs-wire) | Real-time chat — 1:1 and group rooms, integrated with Gate SSO | Vue 3 · Socket.io · Prisma · Postgres |
| [`labs-craft`](https://github.com/Proddy-0/labs-craft) | Academic hub — interactive landing organizing CTI coursework summaries with glassmorphism design | HTML · CSS · JavaScript · Docker |

### 🖥️ Homelab

Self-hosted on Ubuntu Server with 25+ Docker containers. Notable pieces: Nginx Proxy Manager + Cloudflare Tunnel for public access, Authelia for SSO, AdGuard Home for network-wide DNS filtering, Vaultwarden, Jellyfin, SearXNG, Memos. Everything stitched together over Tailscale, storage unified with MergerFS.

It's where I learn infrastructure the hard way — by breaking it on weekends.
